# GoWeb — Unified Growth Platform for Saudi Businesses

**Marketing, CRM and sales in one platform.** GoWeb connects the whole customer journey, from the first touch to a repeat customer, in a single system designed for the Saudi market.

🔗 Live product: **[goweb.sa](https://goweb.sa)**

> This repository is a project showcase. It contains documentation only — the production source code is private.

---

## Overview

GoWeb GRP is a multi-tenant SaaS platform built for Saudi businesses. Instead of stitching together separate tools for advertising, customer relationships and sales, GoWeb puts them in one place:

- **Marketing** — attract the right customers and measure every campaign's return.
- **CRM** — keep a full record of every customer and interaction, and qualify leads.
- **Sales** — manage opportunities, guide the team and close more deals.

Leads arrive from ads, the website, WhatsApp, forms and calls, and land in one customer profile with a complete interaction history.

## Key features

**Marketing workspace**
- Campaign management across Meta, TikTok, Google, Snapchat, LinkedIn and X.
- Lead capture from ads, the website, WhatsApp, forms and calls into one inbox.
- Campaign comparison with cost per lead (CPL), customer acquisition cost (CAC), ROAS and qualified-lead counts.

**CRM**
- One customer profile per contact, with the full interaction timeline.
- Lead qualification and follow-up tracking.
- Team activity: calls, messages and notes in one record.

**Sales**
- Opportunity pipeline with stages and owners.
- Deal movement and follow-up tracking for sales teams.

**Platform**
- True multi-tenancy: each business works in its own isolated workspace.
- Role-based permissions across teams and roles.
- Real-time notifications and live updates.
- Online payment flows for subscriptions.
- API-first design, so the dashboard and other clients consume the same backend.
